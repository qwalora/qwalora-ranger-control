operational impact. "Blocker" means it must be closed before controlled production promotion.

## Residual-risk notes
- R1 and R2 are the two items that most threaten the platform's core value (signed, tamper-evident research evidence) and must be closed first.
- R3 is a classic "it works in tests, unproven in production" recovery gap; passing backup tests do not prove a live, restorable backup exists.
- R4 is an honestly documented limitation in the code itself; closing it is required only if an enterprise-grade, compromise-resistant audit guarantee is claimed.
